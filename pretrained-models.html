Recommendations Which model to choose by scenario
Complex reasoning or generation
GPT-4
When the task requires sophisticated multi-step reasoning, code generation, or multimodal input and cost and latency are acceptable, GPT-4 provides unmatched capability through the API.
Custom NLP classification on private data
BERT-base / RoBERTa
When the organization cannot send data to an external API and needs a fine-tunable model for sentiment analysis, NER, or QA, BERT provides strong performance on modest hardware with full data control.
Self-hosted generative AI
LLaMA 3 (8B or 70B)
When generative capability is needed on-premises for privacy or compliance reasons, LLaMA 3 provides open weights and strong performance, fine-tunable via LoRA on a single GPU.
General vision fine-tuning
ResNet-50
The default backbone for image classification fine-tuning tasks where accuracy and speed are both important and deployment is on standard server hardware.
Mobile or edge vision deployment
MobileNetV2
When model must run on a smartphone, IoT device, or embedded system with hard memory and latency constraints, MobileNetV2 is the clear choice.
Highest vision accuracy
EfficientNet-B4
When maximum image classification accuracy is the primary objective and GPU resources are available, EfficientNet-B4 outperforms ResNet-50 at fewer parameters.
Structured / tabular data (standard size)
XGBoost
The default choice for tabular classification and regression. Best accuracy on most structured datasets, natively supported by SHAP for interpretable feature attributions.
Large-scale tabular data or fast retraining
LightGBM
When the dataset exceeds several million rows or retraining schedules are tight, LightGBM trains 10–20x faster than XGBoost with comparable accuracy.
