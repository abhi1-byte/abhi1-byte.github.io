Tabular Data Structured / spreadsheet data
Decision Tree
Supervised

Builds a tree of yes/no questions based on feature values. At each node, the algorithm picks the attribute that best separates the data, branching until every path ends at a class label.

Tabular
Use cases: loan approval, disease diagnosis, fraud detection, customer churn prediction
Random Forest
Supervised

An ensemble of many Decision Trees trained on random subsets of the data. Each tree votes on the output, and the majority vote becomes the final prediction. Reduces overfitting compared to a single tree.

Tabular
Use cases: credit scoring, stock price prediction, medical risk stratification, e-commerce recommendations
Gradient Boosting
Supervised

Builds trees sequentially, where each new tree corrects the errors made by the previous ones. Iteratively reduces prediction error by focusing on the hardest cases. XGBoost and LightGBM are popular variants.

Tabular
Use cases: Kaggle competitions, insurance risk scoring, click-through rate prediction, supply chain forecasting
K-Means Clustering
Unsupervised

Partitions data into K clusters by minimizing the distance between each data point and its assigned cluster center. Repeats until cluster assignments stabilize. Requires no labels.

Tabular
Use cases: customer segmentation, market research grouping, anomaly detection, document topic grouping
Linear Regression
Supervised

Fits a straight line (or hyperplane) through data points to predict a continuous output variable. The simplest and most interpretable regression method; forms the foundation for many advanced models.

Tabular
Use cases: house price estimation, sales forecasting, energy consumption prediction, salary modeling
👁
Computer Vision Image and video data
Convolutional Neural Network (CNN)
Supervised

Uses convolutional layers to scan images with small filters, learning spatial patterns like edges, textures, and shapes. Stacked layers learn increasingly abstract visual features from raw pixels.

Computer Vision
Use cases: facial recognition, medical image diagnosis, autonomous vehicle perception, product defect detection
YOLO (Object Detection)
Supervised

You Only Look Once: divides the image into a grid and simultaneously predicts bounding boxes and class labels for all objects in a single forward pass, enabling real-time detection.

Computer Vision
Use cases: security surveillance, traffic monitoring, sports analytics, retail shelf inventory scanning
💬
Natural Language Processing Text and language data
GPT (Transformer)
Supervised

A large Transformer model trained to predict the next token in a sequence. Self-attention layers allow it to relate every word to every other word in context. Fine-tuned for conversation, summarization, and code generation.

NLP Generative AI
Use cases: chatbots, document summarization, code generation, customer support automation
BERT
Supervised

Bidirectional Encoder Representations from Transformers: reads text in both directions simultaneously to build deep context understanding. Optimized for classification and understanding tasks rather than generation.

NLP
Use cases: sentiment analysis, question answering, named entity recognition, search engine relevance ranking
✦
Generative AI Content creation models
GAN (Generative Adversarial Network)
Unsupervised

Two neural networks compete: a Generator creates synthetic data and a Discriminator judges whether it is real or fake. This adversarial dynamic pushes the generator to produce increasingly convincing outputs.

Generative AI Computer Vision
Use cases: synthetic image generation, deepfake creation, data augmentation, fashion design prototyping
Diffusion Model
Supervised

Learns to reverse a gradual noise-addition process. During training, images are progressively destroyed with noise. The model learns to reconstruct them. At inference, it starts from pure noise and iteratively refines until a coherent image emerges.

Generative AI Computer Vision
Use cases: Stable Diffusion, DALL-E image generation, video synthesis, drug molecule design
